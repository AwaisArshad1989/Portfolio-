PitchDeck – Multimodal AI Pitch Coaching System

Final Year Project (FYP)
Video Demo Ready Click below to upload or select a demo video
or drag & drop your MP4/WebM video here

Project Overview

PitchDeck is a full-stack multimodal AI coaching platform that evaluates startup pitches in real time. By concurrently processing live video feeds and audio streams, PitchDeck delivers fine-grained, quantitative feedback on body language, eye contact consistency, speech fluency, vocal cadence, and argument conviction.

System Architecture

[ User Video Stream ] ──> MediaPipe Vision Pipeline ──> Gaze & Posture Metrics ──┐
                                                                                 ▼
[ User Audio Stream ] ──> Distil-Whisper ASR ────────> Speech Transcription ────> [ Groq LLM (Llama 3.3) ]
                                                                                 │
[ Real-Time React Dashboard ] <──────────────── Actionable Coaching Scores & Radar <──┘

Key Technical Features

  • Computer Vision Tracking: Employs Google MediaPipe for facial landmark estimation, head pose yaw/pitch tracking, and posture orientation.
  • Sub-Second ASR: Distil-Whisper integration achieves low-latency audio transcription and filler-word frequency detection.
  • Ultra-Fast LLM Reasoning: Groq-accelerated Llama 3.3 model provides instant semantic critique on delivery, persuasion, and clarity.
  • Interactive Dashboards: React-based radar charts, temporal eye-contact plots, and summary coaching reports.

Project Overview

An autonomous end-to-end multi-agent AI research framework designed to automate the scientific discovery process. Collaborating agents formulate scientific hypotheses, write Python simulation and modeling code, run execution in sandboxed environments, autonomously debug stack trace errors, and synthesize publication-style reports.

System Architecture

[ Scientific Prompt ] ──> [ Lead Scientist Agent ] ──> Formulate Hypothesis
                                    │
                                    ▼
                         [ Python Code Generator ] ──> Generate Scripts
                                    │
                                    ▼
                         [ Isolated Sandbox Exec ]
                                  │       │
                      (On Error)  │       │  (On Success)
                                  ▼       ▼
                       [ Debugger ]     [ Verification Agent ] ──> Check Statistical Rigor
                       (Self-Patch)               │
                                                  ▼
                                        [ Research Synthesis Agent ] ──> Scientific Paper

Key Technical Features

  • Agent Specialization: Role-delineated architecture with Lead Scientist, Code Generator, Execution Engine, Debugger, and Verifier.
  • Autonomous Self-Healing: Agents read runtime stack traces, hypothesize bugs, and iteratively patch code until successful execution.
  • Verification Rigor: Verification agents scrutinize p-values, sample distributions, and statistical validity to prevent hallucinated conclusions.
  • Ollama & Llama 3: Seamless support for local inference via Ollama and remote cloud endpoints.

Walmart Data Warehouse with OLAP Analytics

Data Warehouse / OLAP
Video Demo Ready Click below to upload or select a demo video
or drag & drop your MP4/WebM video here

Project Overview

Built an end-to-end enterprise data warehouse using Python and MySQL, transforming raw retail data into a structured Star Schema architecture. Engineered for high-performance analytical processing, enabling multi-dimensional intelligence across revenue, sales velocity, customer spending behaviors, and supply chain timelines.

System Architecture

[ Raw Retail Datasets ] ──> [ Python / Pandas ETL Engine ] ──> [ Data Cleaning & Validation ]
                                                                             │
                                                                             ▼
[ 20 OLAP Queries Engine ] <── [ Star Schema: FactSales + 5 Dim Tables ] <── [ Hybrid Join Loader ]
            │
            ▼
[ Executive BI Insights: Revenue Trends, Customer Spending, Margin Analysis ]

Key Technical Features

  • Star Schema Dimensional Modeling: Developed Fact and Dimension tables for customers, products, stores, suppliers, and temporal dates to optimize query throughput and minimize redundancy.
  • Automated ETL Pipeline: Built a robust data extraction, cleansing, and transformation pipeline using Pandas and MySQL to convert dirty raw retail datasets into clean relational records.
  • Hybrid Join-Based Loading: Implemented optimized Hybrid Join loading strategies ensuring high-speed bulk ingestion with complete referential integrity.
  • 20 Complex OLAP Queries: Formulated 20 analytical queries (roll-up, drill-down, slice-and-dice) to extract actionable business insights on sales volumes, revenue trajectories, and customer spending habits.
